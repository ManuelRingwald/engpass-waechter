# Engpass-Wächter

Öffentliche Fassung eines privaten Prototyps: gebaute Web-App und tägliche Daten aus den
Lieferengpassmeldungen des BfArM (Nutzung nach § 4 Datennutzungsgesetz, Kontaktdaten entfernt).
